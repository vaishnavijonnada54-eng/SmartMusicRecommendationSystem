# 🎵 Smart Music Recommendation System

## About the Project

The Smart Music Recommendation System is a Python-based desktop application designed to make music discovery easier and more enjoyable. It provides users with music recommendations based on their preferences and mood.

The application uses a content-based recommendation approach to identify and suggest music with similar characteristics. It also provides an interactive graphical interface through which users can explore recommendations and access additional music-related features.

## Features

- **Mood-Based Recommendations:** Discover music based on your current mood.
- **Music Recommendations:** Get suggestions based on music similarities.
- **Surprise Me:** Explore unexpected music suggestions.
- **Music Facts:** Discover interesting information about music.
- **Statistics and About:** Access additional application information.

## Technologies Used

- Python
- Tkinter / CustomTkinter (depending on the GUI modules used)
- Pandas
- Scikit-learn (if used in the recommendation module)

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Python is installed.
4. Install the required dependencies.
5. Run the appropriate Python application entry-point file.

Example:

```bash
python home.py
```
